**Tata Prashikshan-23**

## 💡 Project Overview
Developed a **dynamic web application** that delivers **real-time local news and weather updates** using public APIs.  
The project focused on enhancing user interactivity, modular web design, and API-driven data integration.

---

## 🧠 Key Responsibilities
- Designed and implemented a **responsive front-end** using **HTML, CSS, and JavaScript**.  
- Integrated **Weather and News APIs** to fetch live updates dynamically.  
- Developed **modular UI components** for easy scalability and maintenance.  
- Focused on **asynchronous JavaScript (Fetch API)** to improve data loading efficiency.  
- Ensured the app provided a **clean, intuitive interface** for users to access information quickly.

---

| Technology | Purpose |

- Gained hands-on experience in **real-world project design and deployment workflow**.
